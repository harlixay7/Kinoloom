The settings file

            
            
            
          

          
Every setting in one file (tool/settings.yaml, shown as JSON). Most have their own page;
            change one here only when you know what it does, since a wrong value can stop renders.
            Secrets show as ******** and keep their value when left as they are.

          
        

      


      

        

          
Use model files you already have

          
If ComfyUI or another program already has some of Kinoloom's model files, under any name, Kinoloom uses them instead of downloading them again. Paste the folder they are in (its subfolders are searched too) and press Find. Your files stay where they are: Kinoloom links each one, a second name for the same file that takes no extra space (on another drive the links go in a Kinoloom-models folder at the top of that drive). Only a file that can't be linked, on an exFAT USB drive for example, needs a copy, and Kinoloom asks first.

          

            
            
          

          

            

            

            

              
              
            

          

        

        

          
Model folders

          
Kinoloom also reads model files from these folders, where they sit under Kinoloom's names and subfolders (diffusion_models\, loras\, ...; ComfyUI's older unet\ and clip\ count too). Restart Kinoloom after a change, so its render engines see it.
