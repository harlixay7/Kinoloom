Use model files you already have

          
If ComfyUI or another program already has some of Kinoloom's model files, under any name and in any folder, Kinoloom uses them instead of downloading them. Paste the folder they are in (from Explorer's address bar; its subfolders are searched too) and press Find. Your files stay where they are, under their own names: Kinoloom links each one, which gives the same file a second name with no extra space (on another drive, the links go in a Kinoloom-models folder at the top of that drive). Only a file that can't be linked (on an exFAT USB drive, say) needs a copy, and Kinoloom asks first.

          

            
            
          

          

            

            

            

              
              
            

          

        

        

          
Model folders

          
Kinoloom also reads model files from these folders, where they sit under Kinoloom's names and subfolders (diffusion_models\, loras\, ...; ComfyUI's older unet\ and clip\ count too). Restart Kinoloom after a change, so its render engines see it.
